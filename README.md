# Orbit: Space Exploration Quiz

Orbit is a standalone, 10-question space exploration quiz. Choose an answer for each question, follow your score and progress, and see an emoji reaction with your final results. Correct and incorrect answers receive animated feedback, and the page supports light and dark system themes.

## Run locally

No build step, server, or dependencies are required. Open `index.html` directly in a modern web browser.

## GitHub Pages

The site is deployed from the `main` branch with the GitHub Actions workflow in `.github/workflows/pages.yml`. Every push to `main` runs the static-site check and deploys `index.html` to GitHub Pages. The workflow can also be run manually from the Actions tab.
